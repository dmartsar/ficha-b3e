# Cómo colaborar

¡Gracias por querer mejorar Plan y fichas de buceo!

- **Propón ideas, no código.** Usa el enlace «Proponer una mejora» del programa o la pestaña *Issues* de este repositorio (plantilla «Proponer una mejora»).
- **No se aceptan cambios de código** (*pull requests*): se cerrarán sin revisarlos. El autor programa cada mejora que decida incluir.
- **Las propuestas son públicas.** No incluyas nombres, teléfonos, datos de salud ni ningún dato personal.
- Al enviar una propuesta aceptas que el autor use la idea libremente, sin compensación y sin obligación de incluirla.
