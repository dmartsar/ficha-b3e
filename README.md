# Ficha de buceo · B3E

Formulario vacío para la salida de buceo. Se publica en https://dmartsar.github.io/ficha-b3e/

La página es estática: lo que se rellena se queda en el móvil de cada buceador y solo sale cuando él lo manda por WhatsApp al organizador. Este repositorio no contiene fichas, planes ni datos personales.

No se edita a mano: se genera desde el repositorio de la pizarra (`tools/prepare-ficha-site.mjs`).
